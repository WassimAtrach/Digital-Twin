Legacy Retrofit Traffic Control Secure Integration

Legacy — an old, traditional traffic light. It just runs a fixed timer (e.g. 30 seconds green, 30 seconds red), with no internet connection, cameras, or smart sensors.

Retrofit — taking that legacy light and upgrading it without tearing down the poles: adding smart cameras, an edge computer, and a network link so it can react to real traffic in real time. That upgraded link is exactly what these attacks target.
